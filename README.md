# Programmering C – GitHub Pages elevskabelon

Denne mappe kan bruges som udgangspunkt for en elevportfolio i Programmering C.

## Filer

- `index.html` – elevens færdige hjemmeside
- `style.css` – hjemmesidens design
- `blokke.html` – byggeklodser, som kan kopieres til `index.html`
- `billeder/` – screenshots, diagrammer og fotos
- `python/` – elevens Python-filer

## Enkel arbejdsgang

1. Åbn mappen i VS Code.
2. Redigér `index.html`.
3. Gem filerne.
4. Se siden lokalt ved at åbne `index.html` i en browser.
5. Commit ændringerne i VS Code.
6. Push / Sync til GitHub.
7. GitHub Pages viser den publicerede side.

## Forslag til commit-beskeder

- `Tilføjet første projekt`
- `Tilføjet billede fra Wokwi`
- `Rettet fejl i Python-kode`
- `Tilføjet testresultater`
- `Opdateret refleksion`

## GitHub Pages

Repository'et kan publiceres direkte fra en branch, fx `main`.
Ved en helt simpel HTML-side er der ikke behov for en build-proces.

## Læreridé

Lad eleverne starte med kun at ændre:
- tekst
- links
- billeder
- Python-kode

Senere kan de få lov til at ændre struktur og CSS, hvis det er relevant.
