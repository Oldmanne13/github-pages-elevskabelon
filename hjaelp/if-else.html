Forside Hjælp

Hvad er if?

En if-sætning bruges til at træffe en beslutning i programmet.

Koden under if bliver kun udført, hvis betingelsen er sand. 

tal = 10

if tal > 5:
    print("Tallet er større end 5")

Da variablen tal indeholder værdien 10, er betingelsen sand.

If og else

Med else kan programmet gøre noget andet, hvis betingelsen ikke er sand. 

tal = 3

if tal > 5:
    print("Tallet er større end 5")
else:
    print("Tallet er 5 eller mindre")

Her bliver koden under else udført, fordi 3 ikke er større end 5.

Sammenligninger

I en if-sætning kan man sammenligne værdier på forskellige måder. 

tal == 10    # lig med
tal != 10    # ikke lig med
tal > 10     # større end
tal < 10     # mindre end
tal >= 10    # større end eller lig med
tal <= 10    # mindre end eller lig med

Bemærk, at man bruger == til at sammenligne to værdier. 

tal = 10

if tal == 10:
    print("Tallet er 10")

Flere muligheder med elif

Hvis der er flere mulige betingelser, kan man bruge elif. 

temperatur = 22

if temperatur > 25:
    print("Det er varmt")

elif temperatur > 15:
    print("Temperaturen er behagelig")

else:
    print("Det er koldt")

Programmet undersøger betingelserne oppefra og ned. Når en betingelse er sand, bliver dens kode udført.

If med en variabel

En boolean kan indeholde værdien True eller False. 

led_taendt = True

if led_taendt:
    print("LED'en er tændt")
else:
    print("LED'en er slukket")

If-else og LED

Her bruger vi en variabel til at bestemme, om LED'en skal være tændt eller slukket. 

from machine import Pin

led = Pin(5, Pin.OUT)

led_taendt = True

if led_taendt:
    led.value(1)
else:
    led.value(0)

Hvis led_taendt er True, bliver LED'en tændt.

Hvis værdien ændres til False, bliver LED'en slukket. 

led_taendt = False

If-else med en knap

En if-sætning kan bruges til at kontrollere, om en knap er trykket ned. 

from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)
knap = Pin(4, Pin.IN, Pin.PULL_UP)

while True:

    if knap.value() == 0:
        led.value(1)

    else:
        led.value(0)

    sleep(0.1)

Når knappen trykkes ned, bliver værdien 0, og LED'en bliver tændt.

Når knappen ikke er trykket ned, bliver LED'en slukket.

Eksempel med temperatur

If-else kan også bruges til at reagere på målinger fra en sensor. 

temperatur = 28

if temperatur >= 30:
    print("Temperaturen er høj")

elif temperatur >= 20:
    print("Temperaturen er normal")

else:
    print("Temperaturen er lav")

Her vælger programmet en handling afhængigt af temperaturen.

Husk indrykningen

Python og MicroPython bruger indrykning til at vise, hvilken kode der hører til en if-sætning. 

tal = 10

if tal > 5:
    print("Denne linje hører til if")

print("Denne linje kører altid")

Linjen under if skal derfor rykkes ind.
