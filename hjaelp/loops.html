Forside Hjælp

Hvad er en løkke?

En løkke bruges til at gentage den samme kode flere gange.

I Python og MicroPython bruger man især while og for. 

while True:
    print("Hej")

Denne løkke fortsætter, så længe programmet kører.

While-løkke

En while-løkke gentager kode, så længe en betingelse er sand. 

tal = 0

while tal < 5:
    print(tal)
    tal = tal + 1

Programmet udskriver tallene fra 0 til 4.

Variablen tal bliver én større, hver gang løkken kører.

Uendelig while-løkke

På en ESP32 bruger man ofte while True, fordi programmet skal køre hele tiden. 

while True:
    print("Programmet kører")

True er altid sand, så løkken stopper ikke af sig selv.

Blinkende LED med while

En uendelig løkke kan bruges til at få en LED til at blinke hele tiden. 

from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)

while True:
    led.value(1)
    sleep(1)

    led.value(0)
    sleep(1)

Når programmet når bunden af løkken, starter det automatisk forfra.

For-løkke

En for-løkke bruges ofte, når man ved, hvor mange gange noget skal gentages. 

for i in range(5):
    print(i)

Programmet udskriver: 

0
1
2
3
4

range(5) giver værdierne fra 0 til 4.

Start og slut med range

Man kan også bestemme, hvilket tal en for-løkke skal starte ved. 

for i in range(1, 6):
    print(i)

Programmet udskriver tallene fra 1 til 5.

Det sidste tal i range() bliver ikke taget med.

Spring mellem tallene

Et tredje tal i range() bestemmer, hvor stort springet skal være. 

for i in range(0, 11, 2):
    print(i)

Programmet udskriver: 

0
2
4
6
8
10

Blink LED et bestemt antal gange

En for-løkke er nyttig, hvis LED'en kun skal blinke et bestemt antal gange. 

from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)

for i in range(5):
    led.value(1)
    sleep(0.5)

    led.value(0)
    sleep(0.5)

Her blinker LED'en 5 gange.

Løkke med en variabel

Antallet af gentagelser kan gemmes i en variabel. 

antal = 10

for i in range(antal):
    print("Gentagelse", i)

Hvis programmet skal gentage koden flere gange, behøver man kun at ændre værdien af antal.

While og if sammen

Løkker og if-sætninger bruges ofte sammen. 

tal = 0

while tal < 10:

    if tal == 5:
        print("Nu er tallet 5")

    print(tal)

    tal = tal + 1

Løkken gentager koden, mens if-sætningen undersøger værdien undervejs.

While med en knap

På en ESP32 kan en løkke hele tiden kontrollere, om en knap bliver trykket ned. 

from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)
knap = Pin(4, Pin.IN, Pin.PULL_UP)

while True:

    if knap.value() == 0:
        led.value(1)
    else:
        led.value(0)

    sleep(0.1)

Programmet kontrollerer knappen igen og igen. Når knappen trykkes ned, tændes LED'en.

break

Kommandoen break kan bruges til at stoppe en løkke. 

tal = 0

while True:
    print(tal)

    tal = tal + 1

    if tal == 5:
        break

print("Løkken er slut")

Når tal bliver 5, stopper while-løkken.

Husk indrykningen

Koden, der skal gentages, skal være rykket ind under løkken. 

for i in range(3):
    print("Denne linje gentages")

print("Denne linje kører kun én gang")

Indrykningen fortæller Python, hvilken kode der hører til løkken.
