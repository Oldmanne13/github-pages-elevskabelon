Blinkende LED

MicroPython på ESP32

Forside Hjælp

Grundlæggende eksempel

Først importerer vi Pin og sleep. Derefter opretter vi LED'en som output. 

from machine import Pin
from time import sleep

led = Pin(5, Pin.OUT)

while True:
    led.value(1)
    sleep(1)

    led.value(0)
    sleep(1)

Kortere løsning

from machine import Pin
from time import sleep

led = Pin("LED", Pin.OUT)

while True:
    led.toggle()
    sleep(1)
